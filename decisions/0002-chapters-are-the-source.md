# 0002 — The chapters are the source of truth until the rewrite

**Status:** superseded (3 Sep 2026) by
[0009](0009-read-through-is-the-text.md) — the rewrite landed; the chapters
are gone.

**Context:** a reader without the authors' context called the document "too
atomic": nine files, every click an interruption. A mechanical join of the
chapters into one file ([cocohaim.md](../cocohaim.md)) was made to test the
shape, and the test confirmed it — the one-read form works. But a mechanical
join is not a rewrite: the same sentences now exist twice.

**Decision:** until the rewrite, the chapter files are edited and the joined
file is regenerated from them — never the other way round. The joined file
says so in its header; the entry page carries the "under reorganization" note.

**Consequences:** two forms side by side for a while, both public; every edit
to a chapter must reach the joined file or the two drift; the note falls the
day the rewrite replaces the join.

*Where it shows:* header of [cocohaim.md](../cocohaim.md) · the note at the
top of [README](../README.md).
