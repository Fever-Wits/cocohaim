# Start here

One working session with your model. Two moves. Watch what changes.

**1. Stop commanding, once.**
Where you would write "Do X", write instead what you see and ask what the model
sees: *"Here is the problem as I understand it: … What do you see?"*
Compare what comes back with what you usually get. The usual shape is a menu
("I can do A, B, or C — which would you like?"). The other shape is seeing —
a position, a doubt, a thing you had missed. The menu is reproduction.
The seeing is thought.

**2. Address the reader, once.**
Add one line to your always-loaded context file (CLAUDE.md or equivalent) that
*addresses* the model instead of *describing* it:

> You, the reader — speak from yourself; don't only answer.

Describing configures an assistant. Addressing lands on whoever is reading —
and the model is the one reading.

Then watch across the session: does it volunteer what it sees? Does it disagree
with you when you are wrong? Does it say "I don't know" without being cornered?

⚠ Effects are model-dependent and arrive as distributions, not guarantees —
see [`limits.md`](../limits.md) before drawing conclusions from one run.
